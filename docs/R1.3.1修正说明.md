# R1.3.1 界面与机房整体路由修正版

2026-10-26（北京时间）。本补丁用于已完整解压并运行的 R1.3，不需要重新下载全量数据。

## 对应的界面依据

采用本聊天中最后确认的四页顶部导航、橘红折带品牌图标及“光路调度智能分析”名称。路由页对照用户提供的 R1.2 参考图：左侧查询条件，右侧搜索结果、四种排序、方案摘要、连接顺序图、逐段资源表。资源页对照四张统计卡、筛选栏、宽表和分页参考图，去除底部常驻详情。节点类型保留分类计数选框、编辑与集群管理。未恢复已取消的更新中心。

本次确实重做了输入框、按钮、卡片、导航和方案区；设置是中性工具按钮，仅当前主页面显示青色下划线。表头按字体与内边距自动增高，默认列宽按可用空间分配，仍支持手动列宽、行高和分隔区调整。旧版有问题的布局设置不再套用。

设计图片并非可直接执行的页面文件，不能声称每个像素均与生成图片相同。本目录的运行截图来自实际编译的 WinForms 程序在 Wine 兼容环境中运行，使用样例数据与文泉驿中文字体；不是 Windows 实机截图，字体和系统控件外观可能与客户 Windows 略有区别。

## 连接顺序图

支持鼠标滚轮横移、按住左键拖动、底部滚动条、左右方向键以及 Home/End。长名称可悬停查看。真实中继段用实线，整体内成员关系用虚线。机房整体显示机房名称并保留实际成员名称和真实逐段资源，不添加虚构长度或资源容量。

## 机房作为整体

新增“节点类型 → 机房归属”。仅使用明确的“机房名称/所属机房”和“始端机房/终端机房”字段，不使用上联机房、站点、地址相似或名称前缀代替所属机房。

同一机房内的 ODF/ODB 及其明确归属的设施按机房核心参与路由；同组中的每个真实中继段和容量仍独立保留。起终点可搜索机房名称，一次选择整体，亦可选择具体设备。机房内的虚线不增加实际段数、距离或跳纤次数，内部容量未经单独核验。

光交箱有明确所属机房时，归属字段可以已匹配，但是否纳入机房整体路由需额外确认：首次发现给出提示，在机房归属的成员清单中核对并启用，也可暂停。没有确认时不会借既有集群关系绕过这一步。

同一设施对应多个所属机房标为“需核对”，不自动归并；允许从已有表格值中人工选择。集群关系跨越多个机房核心或涉及尚未确认的光交箱时，不静默合并，并在集群管理显示原因。只出现一次的机房也可以搜索，不要求有两个设施。

本地数据库首次加载旧 R1.3 资源时补建机房索引；这属于数据整理，不替换原中继段。类型表再次导入时同步读取归属；同一来源按最新文件替换归属，保留人工选择。手动确认与当前表格不再匹配时会重新核对。

## 补丁与空间

补丁只含三个程序文件、一份派生归属 JSON 和说明、校验清单。没有原始表格，没有 resources.db / personal.db，也不包含运行库副本。安装会先校验当前 R1.3 文件与补丁 SHA256，只保存一份小型程序补丁备份，失败时恢复本次修改。

首次启动把派生 JSON 写入本地结构化库后清理该临时 JSON；不会删除用户上传的任何表格。已经由用户导入的同来源归属不会被基线覆盖。后续类型表或归属表仍通过导入按来源更新，不能据此声称已部署云端更新。数据库保存有效信息，仍会占用磁盘。

使用安装脚本后，仍从原目录的“光路调度智能分析.exe”启动，窗口标题显示 R1.3.1。确认使用正常后，可删除补丁下载文件和“补丁备份/R1.3.1”。不要删除运行目录的数据库。

## 验证边界

核心检查 106 项通过，含 720 组独立穷举路径对比及机房、归属冲突、光交箱启用、旧库迁移、重复更新和取消保留原数据检查。全量数据仍为 272,561 条中继段、264,608 个实际设施节点，208.21 米 / 1 次跳纤黄金路径通过。

WinForms 交互检查分别在 96 DPI 和 144 DPI 的 Wine 环境执行：设置中性状态、首屏导航、真实搜索与逐段表、表头高度、滚轮、拖动、列宽保留、下拉输入和点击选点。仍需客户 Windows 环境验收；未将兼容环境等同 Windows 实机。
