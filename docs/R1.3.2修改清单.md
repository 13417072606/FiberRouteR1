# 光路调度智能分析 R1.3.2 修改清单

2026-10-27。适用于已有 R1.3 / R1.3.1 的 Windows x64 用户。

1. **选中色调**：方案下拉、表格选中行与排序按钮使用浅青底、深色字；设置保持中性按钮，不再像当前页面。
2. **紧凑布局**：默认 1280×800，可缩放、最大化；压缩顶部与卡片留白，查询按钮常驻；支持 100% / 150% 显示缩放。分隔区可以拖动。
3. **资源详情**：“逐段资源详情”改为“资源详情”，删除该表可见 ID，保留序号、真实起终设备、长度、空闲/总芯及需求后余量。底层 ID 仍用于匹配、去重和导出。
4. **机房节点折叠**：ODF / ODB 按明确所属机房形成整体，主图不再重复绘制首尾的代表设施、接续设施与“归属关系”虚线。单击整体可查看实际成员，资源详情继续列出真实中继段端点。
5. **候选路由**：删除“综合候选”，使用“满足需求、距离最短、跳纤最少、余量最多”。没有虚构综合评分。方案选择可下拉，当前方案可收起；导出当前或全部方案有独立菜单。“满足需求”遵循已配置的约束；搜索仍有数量、时间与扩展上限，达到上限会显示不完整结果。
6. **光交归属提示**：明确且无冲突的光交所属机房参与整体分析；有人工暂停的继续暂停。相关路由节点显示橙色“含光交 · 归属提示”，悬停/单击查看光交完整名称、所属机房及核对说明。取消启动弹窗。归属冲突仍隔离，不能因类型是光交就自动将确认状态改成需核对。
7. **需求芯数筛选**：默认勾选“仅看满足需求芯数的方案”，列表与图中均隐藏芯数不足的路由；取消后可查看明确标“芯数不足”的参考方案。满足芯数的候选优先，参考方案仍受跳纤、类型规避、节点规避及搜索上限约束。勾选时立即隐藏先前不足方案。无真实中继段的内部关系标记容量待核验，不虚构容量。
8. **端点豁免**：只删除界面文字，保留现有规则：类型规避作用于中间节点，起终点保留类型豁免；具体规避节点与起终点冲突仍会拦截。
9. **无框表格**：去除单元格横线、竖线和深色行头，使用浅表头、留白及浅色选中；表头按字体与内容适配。保留列宽、顺序、分区调整；右键可设置行高、自动适应、列设置及恢复布局，布局会保存。
10. **单节点拖动**：鼠标拖动单个节点时，相连线条、端点、距离标签实时跟随；仅改变显示位置。空白拖动平移、滚轮横移、键盘左右/Home/End继续可用，提供自动排布与恢复默认。
11. **其余三页视觉和操作**：
    - 中继段资源：四张统计卡使用不同语义图标，长总长度完整显示；类型标签放在设施旁，空闲/总芯合并，每行“详情”，取消底部常驻详情；搜索自动筛选，可选择每页数量。
    - 节点类型：增加标题与说明，保留节点类型/集群管理/机房归属导航、带数量类型胶囊；类型、确认状态、来源分开显示；保留行内修改、人工确认和类型表导入。
    - 数据导入：组织为选择文件—核对字段—预览并导入；必需映射与高级读取选项分层，底部操作常驻。直接读取 CSV/XLS/XLSX。前20条预览不冒充全量校验，失败/停止保留原数据。ID 仍为必需导入字段，隐藏显示不代表删除匹配依据。
12. **品牌原图与等比缩放**：支持将原始 PNG 放在运行目录 `资源/品牌原图.png`，应用直接读取原图，名称旁等比显示，并生成 16/24/32/48/64/128/256 多尺寸 ICO 用于标题栏、任务栏及桌面快捷方式；设置中可创建使用当前图标的桌面快捷方式。普通功能与设施图标不替换。

## 数据与更新

- 原始 Excel/CSV 不复制进程序，数据库仍会占用本地磁盘。重复且无变化的资源导入会跳过；同来源机房归属更新替换旧记录，保留人工选择。
- 本补丁不替换 resources.db / personal.db，不要求重下全量数据。首次应用缺失的机房归属基线后会清理该临时基线文件。
- 不增加更新中心、云后台或激活依赖；可以脱离运营商内网运行。
- 节点确认状态保持：待确认＝仅软件识别且无可用类型表/人工确认；已确认＝表格匹配或人工确认且无明显异常；需核对＝存在明显异常，需要再次核对。

## 安装

关闭程序，运行 `Install-R1.3.2-patch.ps1`。会优先使用当前运行目录，再识别桌面及下载目录；找不到时可选择文件夹。也可指定：

```powershell
& '.\Install-R1.3.2-patch.ps1' -Target "$env:USERPROFILE\Desktop\FiberRouteR1-R1.3\运行目录\光路调度智能分析R1.3"
```

离线安装使用 `-OfflineZip '补丁zip完整路径'`。脚本校验大小、SHA256、内部文件和原版本，先备份小文件再应用；出错回滚，不替换数据库。从原入口启动，标题应为 R1.3.2。
