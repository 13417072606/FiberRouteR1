# R1.3.3 界面修正与导出格式确认稿

本次先交付第 1～5 项修正。第 6 项提供 Excel 格式确认稿，软件暂保留原有 CSV 导出结构，待格式确认后再改正式导出。

1. 规避节点类型改为自动换行的多选框，使用侧栏可用宽度；不再采用自带横向滚动的多列列表。“未识别”始终放在最后。展开条件区按内容计算高度，由整个侧栏统一滚动，底部操作可到达。
2. 默认窗口改为 1380×950（96 DPI），保留自由调整窗口及 DPI 缩放。
3. 删除“已隐藏芯数不足的参考方案”及当前方案下方的未知长度、零长度说明。容量指标改名“路由最小空闲芯数”，表示本路由各段空闲芯数的最小值。未知长度/零长度仍保留在底层结果及 CSV 中。
4. 合并重复的方案下拉选项和摘要，只保留加粗的下拉选项，展示方案号、容量状态、总长度、跳纤次数及路由最小空闲芯数。删除方案的展开/收起按钮；路径和资源详情保持显示。
5. 修复点击路径节点后详情弹窗正文被自动布局压缩、无法阅读的问题。保留完整设施成员和光交归属提示。拖动单个节点时，连线、端点、距离标签仍实时跟随。
6. 生成 `docs/导出模板/路由方案导出模板-待确认.xlsx`：路由总览一条路由一行，各方案分别列出逐段资源、空闲芯数、总芯数、需求及需求后余量，另有长 ID 文本追溯及字段说明。

模板采用本次用户提供的 CSV，共 8 条路由、39 段。方案 07 相邻段端点名称不同，原 CSV 未提供内部衔接依据，已明确标注“内部衔接待核对”。未提供具体纤芯编号时只展示数量，不推断可分配芯号。模板尚未替换软件导出功能。

补丁支持已有 R1.3、R1.3.1、R1.3.2，并可重复安装。只替换应用文件及必要的版本说明/已有机房归属基线，不覆盖 resources.db、personal.db 或用户原始表格。安装前请关闭软件。

界面通过 Wine 上的 Windows WinForms 实际点击、滚轮和拖动检查；未在用户的 Windows 电脑上代为运行。原品牌 PNG 文件的替换仍沿用 R1.3.2 的待补充状态，本次未调整品牌图标。
