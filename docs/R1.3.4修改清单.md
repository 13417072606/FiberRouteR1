# R1.3.4 路由方案 Excel 导出

本次将已确认的表格格式写入软件“导出方案”，可分别导出当前方案或全部候选方案，默认生成 `.xlsx` 工作簿。

- “路由总览”在“终点设施”后加入“跳纤路由”，按该方案实际经过的设施顺序，以 `→` 串联；保留完整名称、自动换行，并按内容调整行高。
- 每条路由单独一个“方案XX”子表，保留逐段长度、空闲芯数、总芯数、需求芯数及需求后余量。总览的“查看详情”和明细的“返回总览”可互相跳转。
- 删除“资源追溯”“字段说明”子表及用户指定的整段页脚说明，不保留这两张隐藏子表或原始 ID 列。
- 跳纤路由使用真实方向的中继段步骤及实际机房/集群内部衔接生成，包含起点、途中及终点的内部设备。相邻重复设施仅显示一次。
- 当前方案导出保留其原方案号，例如方案02导出后仍为方案02。
- 芯数不足参考方案仍按真实数值导出，容量状态明确标注；未知长度保留“未知”，不写成零。仅含内部关系的方案不推断可用芯数。
- 不需要安装 Office、Python 或联网；不打包用户原始表格。文件完整生成后再替换目标，导出失败保留原文件。

`Route-Export-Sample.xlsx` 由软件同一导出模块生成，使用此前用户提供的8条路由、39段CSV作为样例。该CSV缺少方案07一处内部衔接依据，样例行仍明确标注“内部衔接待核对”；软件正常导出使用当前路由的真实内部衔接数据。

安装补丁前关闭程序。支持R1.3、R1.3.1、R1.3.2、R1.3.3升级及重复安装，保留现有数据库和人工维护记录。此前界面调整继续保留。本次未更改品牌图标。
