# R1.4 细节调整与在线更新需求记录

状态：R1.4客户端和发布工具已完成，验证与正式交付见downloads/R1.4。旧版交付文件保持不变。

品牌沿用既定原图要求，效果图中的近似标志不能作为替换品牌原图的依据。主导航仅当前页高亮，设置保持中性。

## 1. 统一分页样式

- 中继段资源、节点类型、集群管理、机房归属使用同一分页控件。
- 使用当前青绿/深蓝/浅边框风格：当前页为青绿实心，其他页白底浅边框，禁用按钮低对比度；长页数用省略号。
- 去掉原生NumericUpDown页码上下小箭头，改为圆角页码输入与“确定”。显示筛选后总数和当前范围。
- 每页数量统一提供20/50/100/200条，默认50条，各页独立记忆。切换数量或筛选时回到第一页；最后一页和空结果有正确的按钮禁用状态。

## 2. 区域字段及每页显示数量

- 中继段源表存在“始端区域”“终端区域”。两端分别展示及筛选，不能简单合并为一个区域，否则跨区中继段会失真。
- 节点类型表中存在“所属地市”“所属区县”“所属镇街”等字段，节点清单至少显示区县级区域，并可查看来源。
- 当前272,561条有效中继段中，219,284条始端区域有值，219,044条终端区域有值。空值显示“未提供”，不按名称猜填。
- 区域只来自明确字段。多来源区域矛盾时保留原始来源及候选值，标记待核对；不静默以第一个值覆盖。
- 当前类型表读取优化分支只返回“设施名称”“机房名称”两列，需要同步改造读取、存储和旧库迁移，不能只给表格增加空列。
- 来源信息只保存文件名/摘要、工作表、记录行号、字段及分析结果，不保留原始文件。旧库未保存的来源行号显示“未记录”，通过重新分析源表或管理方数据包补齐，不能编造。
- 节点类型、集群管理、机房归属新增每页数量选择；资源页原有选择器一并统一。

## 3. 修正多行单元格裁切

已从代码确认两处缺口：

- Layout.cs将当前行高度作为整张表的保存高度；恢复布局时全部行采用同一固定高度，并跳过自动行高。这会裁切其他行的多行名称。
- 资源设施单元格使用自绘类型标签，文字实际可用宽度小于整个列宽，行高测量需要扣除标签及间距。

实现要求：保存的是最小行高/布局偏好，实际行高不得低于当前文字所需高度；绑定数据、翻页、列宽改变、DPI及字体改变后重新测量本页。文字绘制与测量使用相同字体、换行和内边距。保留无网格线、拖动列宽、完整详情/悬浮查看。

## 4. 让排序和筛选真正生效

- 当前表格绑定普通List投影，缺少支持排序的数据源及表头事件处理，点击列标题不一定能排序；集群管理当前只有关键词搜索，没有确认状态筛选。
- 统一实现全结果集先筛选、再排序、最后分页，不能只对当前页排序。
- 节点、集群、机房归属提供“全部/已确认/待确认/需核对”快捷筛选，并显示实际有效状态计数。集群的派生异常（成员失配、跨机房等）必须计入“需核对”，不能只读原始数据库status列计数。
- 集群增加路由启用状态筛选。机房以“任一成员需核对”汇总为需核对，详情可定位异常成员。
- 长度、芯数、成员数按数值排序；缺失长度和真实零长度区分；排序箭头明确升/降序，并以稳定的名称或ID作次序条件。
- 搜索、区域、类型、确认状态等条件组合生效，重置能清除全部条件。导出筛选结果必须与当前完整筛选集一致。

## 6. 设置中的在线更新

- 设置中增加两个独立按钮“检测软件更新”“检测数据更新”，保持简洁，不恢复复杂更新中心。
- 两个按钮都需要支持用户直接在线下载和更新，保留管理方发文件、用户手工更新途径。
- 检测后分别展示当前/可用版本、更新内容和大小。程序更新关闭主程序、备份、替换、失败回退、重新启动；数据更新预览新增/变更/无变化/异常后事务更新。
- 不覆盖客户personal.db、人工确认、个人集群及设置；管理方数据与用户覆盖层分开。遇到人工数据冲突列需核对；无变化记录忽略，过期来源关系按明确的全量/增量规则处理。
- 不将原Excel/CSV日积月累放进程序；清理下载临时文件，备份保留有明确上限。
- 发布服务使用国内可直连HTTPS域名及国内存储/CDN。不依赖GitHub/raw.githubusercontent.com、海外登录、VPN或运营商内网；本地查询不依赖在线检查。
- 国内公网无VPN下载和实际升级需要实测验收。目前没有部署更新服务，效果图不得被解释为已经可在线升级。

现有Updates.cs已有清单签名与下载哈希校验；但设置页未接入，旧更新器仍使用“纤路R1.exe”等旧路径，数据包也不能直接覆盖整个personal.db。R1.4必须适配并验收，不能仅加两个按钮即声称完成。

管理方发布流程见Online-Update-Publishing.md。交付时保持管理员PowerShell下载/安装方式，并提供离线包备用。

分页边界、四种每页数量、跨页排序、组合筛选、空结果；多行名称与列宽/DPI变化；区域缺失/冲突/跨区；挂墙候选隔离及来源追溯；在线更新的版本兼容、无变化跳过、人工保留、下载中断、文件校验失败、回退和国内公网实测，均纳入R1.4检查。
