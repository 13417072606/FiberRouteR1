## 图标原因与素材

现有包内Brand/brand.svg、brand.png和app.ico是简化绘制版本，Y形结构与用户原图不一致。BrandAssets虽然支持资源/品牌原图.png等比生成16/24/32/48/64/128/256像素ICO，但交付包并未携带用户原PNG。这是素材未真正替换，不是用户安装导致。

用户已在聊天中再次展示原图；当前工作区没有该附件原始文件。需补传PNG文件附件后，直接以该文件生成图标。保留原始比例、完整Y形和透明度，不截边、不压扁；主窗口、设置/其他弹窗、启动器、桌面快捷方式同步处理。验证16/24/32/48/256像素、标题栏及任务栏。文件替换与Windows图标缓存是两个问题，不能仅靠清缓存替代正确素材。

## 中继段资源待落实细节

1. 常规1380×950窗口下筛选条合成一行：搜索、始端区域、终端区域、始端类型、终端类型、最少空闲芯数、业务状态、重置、导出筛选结果。
2. 输入文字垂直居中；按内容合理收窄下拉框，完整显示“全部区域”“全部类型”和最长类型。下拉列表宽度独立适配。小窗口按可用空间自适应，正常宽度不出现不必要的水平滚动。
3. 表头固定语义顺序：序号、始端设施、始端类型、始端区域、终端设施、终端类型、终端区域、长度（米）、空闲/总芯、业务状态、操作。
4. 两端类型是独立可排序字段，标签从设施名称单元格移到各自类型列。类型依据现有节点类型数据，不依据预览名称另行猜写。
5. 两个类型筛选按原始资源表始端、终端分别判断，同时选择时采用AND；与区域、业务、最小空闲芯数等条件组合。多标签类型按成员匹配；“未识别”排最后。
6. 页码宽度按位数适配，末页5452完整显示，“确定”留足文字宽度。页容量20/50/100/200条完整显示，分页不占用表格内容区域。
7. 去掉鼠标点击后的虚线焦点矩形；键盘焦点使用细实线/色彩提示，保持键盘可操作。行选中继续浅青底、深色文字。
8. 字体、列宽和DPI变化后重新计算行高；长名称完整换行，数字和详情按钮不截断；表格无竖向网格线，轻量行分隔。
9. 新增类型列后保留用户已有列宽/布局中可兼容的部分；不让旧布局记忆隐藏新字段。导出筛选结果同步包括两端类型字段。

预览中的数值与行仅为布局展示，不修改真实台账。已获得用户确认并在R1.4.1实施；验证见新版本实际运行材料。
