# 管理方发布工具：从哪里开始

黑色窗口显示的是帮助说明，表示程序已正常运行。双击而不带参数不会打包或发布。当前尚未提供线上地址，因此暂时不能让客户在线检测到更新；可以先在本地整理数据和生成发布包。

## 先生成一个数据更新包

1. 在管理方软件导入并复核最新中继段、节点类型、集群和机房归属；确认无误后关闭主程序。
2. 在包含“程序”“数据”的运行目录空白处右键，选择“在终端中打开”，使用PowerShell。
3. 执行以下命令。若设置中的数据目录并非运行目录下的“数据”，把第一行改成该真实路径。

```powershell
$data = Join-Path $PWD '数据'
$out = Join-Path ([Environment]::GetFolderPath('Desktop')) '纤路数据-2026-10-27.1.zip'
& '.\程序\FiberRoute.Admin.exe' pack-data $data '2026-10-27.1' $out
```

成功后桌面出现数据ZIP。该ZIP包含整理后的数据库及清单，供在线发布使用；不能把它当Excel在普通“数据导入”页选择，也不要直接覆盖客户personal.db。暂无服务器时，客户继续通过已有表格导入流程更新。

## 配置服务器后才做的步骤

以下HTTPS地址只是格式示例，必须换成管理方真实可用、客户能访问的HTTPS发布目录。

```powershell
& '.\程序\FiberRoute.Admin.exe' init 'D:\纤路发布工作区' 'https://updates.example.cn/fiber/'
& '.\程序\FiberRoute.Admin.exe' release 'D:\纤路发布工作区' data '2026-10-27.1' $out '本次资源更新说明'
```

- init只做首次初始化；生成公钥、私钥和客户配置。保管private-key.pem，不能上传或发给客户。
- 把工作区client-config/update-service.json发给客户，放入原运行目录的“资源”文件夹。
- 把site目录里的版本ZIP先上传服务器，验证可下载后最后上传site/manifest.json。仅上传site，不上传整个工作区。
- 客户在设置里点击“检测数据更新”，下载后预览差异，再确认更新。

## 软件版本更新

使用开发方提供的新版本完整运行目录，执行pack-program，再执行release software。软件版本必须与DLL版本一致。软件与数据为两个独立渠道。

```powershell
& '.\程序\FiberRoute.Admin.exe' pack-program 'D:\新版本\光路调度智能分析R1.4.1' '1.4.1' 'D:\发布包\软件-1.4.1.zip'
& '.\程序\FiberRoute.Admin.exe' release 'D:\纤路发布工作区' software '1.4.1' 'D:\发布包\软件-1.4.1.zip' '软件更新说明'
```

这两条仅演示以后软件发布的用法，不代表当前已提供1.4.1。

客户人工记录保留，类型/集群/归属冲突需复核；整理后的完整数据快照通过网络传输，本地按差异应用、无变化忽略，原始表格不复制到客户程序中。
