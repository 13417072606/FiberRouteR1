# 管理方发布工具 EXE

安装R1.4.1修订补丁后，双击原运行目录的“管理方发布工具.exe”。这是图形界面，可复用主程序中的运行库，不需要安装开发环境或输入命令；“程序”文件夹必须完整保留。

## 四步日常发布

1. **生成更新包**：选择“数据更新”或“软件更新”，选择来源目录、填写版本号和更新说明，点“生成更新包”。数据来源是主程序中已导入并复核的数据库目录；先关闭主程序。软件来源是开发方提供的新版本完整运行目录。
2. **配置服务**：填写本地管理工作目录、真实客户HTTPS地址及服务器发布目录。点“保存服务配置”；首次自动生成密钥，以后保存沿用原密钥。服务器目录可以是本机目录或有写入权限的单位内网共享。
3. **生成发布清单**：确认更新包，点“生成发布清单”。软件和数据独立，保留另一个渠道。相同版本不允许换成不同内容，请按次增加版本号。
4. **发布与验证**：点“发布到服务器目录”，工具先复制并校验ZIP、最后替换签名清单。再点“验证外网清单”。还需在一台实际客户电脑完成检测、下载、校验和应用测试。

客户配置可点“导出客户配置”，将update-service.json放到客户运行目录的“资源”文件夹；“应用到本机客户端”可直接配置管理员这台电脑。管理员签名私钥只保留在本地工作目录，不能把整个工作目录公开到网站。

## 当前服务器状态

已确认单位有Windows服务器，并表示已有对外网站。尚未收到实际网址、IIS站点名及访问方式，因此交付包不含活动服务器地址，也不声称已经上线。优先复用现有HTTPS网站的/fiber-updates/目录，不需要另租云服务器；具体站点、证书和公网连通由网管确认。随包有Windows服务器部署说明、IIS目录建立脚本及web.config。

普通云盘分享页的提取码、登录、跳转和限额不适合作为自动更新源。免费托管只作为试验备选，不能承诺长期免费或国内访问稳定。

## 数据与文件体积

只读取并分析原始表格，更新包不携带原Excel或原始personal.db。当前协议传输整理后的数据库快照，客户按差异应用并忽略无变化；人工类型、集群、归属选择和设置保留，冲突提示复核。软件与数据各保留最近一次本地回退备份。管理方服务器上的历史版本包可按单位备份策略清理，管理员工作目录不要放进客户程序或网站目录。

首次配置在线服务前，请先把客户端统一升级到R1.4.1修订版：它包含支持新管理方组件的软件升级器。后续软件包最低客户端版本为1.4.1；数据通道仍兼容R1.4。不能让R1.3.x客户端跳过首次安装直接使用尚不存在的在线更新功能。
