# R1.4.2 界面修订

1. 路径示意下增加当前方案跳纤路由。文本直接复用Excel导出的实际设备顺序，包括内部接续端点；支持选择、Ctrl+C和复制路由按钮。长名称自动换行，切换方案同步更新，清空或无结果时清除旧文本。节点拖动及连线、距离标签跟随保留。
2. 中继段表按始端设施、始端区域、始端类型、终端设施、终端区域、终端类型排列。筛选栏同样先始后终；“导出结果”与筛选处于同一行，搜索框吸收剩余宽度，窄窗口才换行。更新该表布局版本，避免旧缓存恢复旧列序。
3. 集群表增加成员名单，保留真实完整名称并测量换行行高；压缩短字段列，给名称、成员名单和原因更大空间。删除底部常驻“成员详情与来源”面板，来源及原因仍可在复核弹窗查看。集群表布局版本同步更新。
4. 输入框按实际字体高度、DPI和父容器客户区重新计算高度与垂直位置；监听布局、字体及DPI变化，解决节点搜索等输入框下沿裁字。数值框同样按字体适配。
5. 只读导入路径框显式使用白色背景，去掉原生只读控件灰色底条；保留文件选择和复制路径功能。

此累计补丁适用于已交付R1.3、R1.3.1、R1.3.2、R1.3.3、R1.3.4、R1.4和R1.4.1。数据库、人工确认和原始表格不替换。已有品牌原PNG时自动重新应用图标。管理方工具及服务协议沿用此前版本。
