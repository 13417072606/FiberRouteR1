# R1.4.3

软件显示名称改为“光路调度路由查询”。新增同名入口，保留旧入口供原快捷方式继续启动；数据目录、品牌PNG和已有更新配置沿用。

- 统一所有主要列表的文字测量与绘制，取消WinForms对已换行文本的第二次换行；调整列宽、字体、DPI、切换页面、加载分页数据时重算行高。节点、中继段、集群、机房和机房成员弹窗保留完整名称及尾缀，悬停可看原文。节点详情可选择复制完整名称。
- 单中继段的复制路由和Excel路由仅列实际两端，不再把同机房内的查询代表设施列成额外路径。多中继段仍保留中间衔接点，起终查询条件单独保留。
- 集群列表分隔器识别中英文括号和嵌套括号，保留括号内逗号。数据库保留原始集群行，站点证据变化后重新分析，不累积上次补齐出来的成员。
- 从设施表“站点名称/位置点”读取独立的所属站点；不代替所属机房。按同一非空站点补齐光交与分纤成员，成员集合相同的重复行归并。表内站点冲突、无法唯一匹配的名称、成员归属重叠继续复核，不模糊猜测。
- 补齐后仍不足两个成员的来源集群不作为有效集群，导入后生成“集群过滤报告.csv”。人工关系保留；与来源关系冲突时暂停，不覆盖人工名单。
- 区分“设施表存在，暂无中继段”和“设施表与中继段均未找到”，列出具体名称。前者保留完整成员名单，仅对当前实际资源中存在的成员参与路由；可参与成员不足两个则暂停。仍保留跨机房冲突阻断规则。
- 针对固定设施导出表，按已知表头识别字面引号格式，每行校验字段数和ID。任意CSV仍使用严格引号规则，避免字段错位导致错认站点。
- POS（不区分大小写）优先归入分纤箱。移除独立“站点”类别，原站点映射为未识别。数据库加载、导入、类型保存采用同一规则。
- 更新包超过24MiB自动生成分片，RSA-PSS签名覆盖有序分片URL、长度、SHA256以及完整ZIP的长度和SHA256。客户端逐片验证、合并再验证；缺片、错序、篡改、跨源和取消都不得进入安装，清理不完整下载。仍兼容原整包下载。新发布清单最低客户端版本1.4.3，客户首次需手动安装本补丁。
- Cloudflare Pages手动上传：服务器发布目录可空，site目录含health.json、index.html和manifest.json禁缓存规则，不包含签名私钥。未添加计费服务或自动上传账号凭据。

专用数据修复基线由本次提供的原始表生成，仅随私有交付提供，不放入公开仓库。程序首次启动把站点证据和原始集群行合入当前数据目录，保留人工关系，不替换resources.db/personal.db整库。公开代码补丁用户也可重新导入两张设施表，再导入集群表，获得同一分析结果。

实表验证：财政局示例为三成员；单中继段2391.53米、0跳纤、ODF12→ODF06；3353个POS节点均为分纤箱。全量分析321个有效候选集群，其中315已确认、6需核对，287可参与当前路由；14条单成员来源行过滤（按原始行计数）。后续表格变更或人工维护会使统计变化。
