- .NET 8 Windows x64 交叉发布完成；192 项核心检查通过。
- Wine 10、中文字体环境下，96 DPI / 144 DPI 各 102 项界面检查通过。包括截取实际“修改”文字像素检查垂直居中、节点与机房完整跨行后缀、六区一县选项、街道归并筛选、未知端点独立处理，以及此前路由、集群、品牌与发布工具回归。兼容环境验证不替代 Windows 原生实机验收。

- 全量验证使用仓库 R1.3 中继段数据库叠加已交付 R1.4.3 设施来源基线：272,561 条中继段、264,608 个节点，读取及计算约 8.8 秒（此执行环境实测）。两端共 545,122 个端点中，12 个缺少可靠线索、250 个存在来源冲突；这些为端点计数，包含同一设施在不同中继段中的重复出现，不等于独立设施数。其余区域均为六区一县。208.21 米既有路由样例通过。

以上数量对应验证快照；客户现有表及后续导入差异可能使待核对数量不同。补丁未打包本次产生的专用缺失清单，客户可在中继段页将始端/终端区域筛选为“未提供”，导出原值、判定及依据进行核对。
