# 光路调度路由查询 R1.4.5

本版为累计更新，包含 R1.4.4 的行高、文字垂直居中、汕头六区一县行政区归并，以及此前的在线升级修复。

- 集群管理依据光交接箱、光分纤箱设施表的后台所属站点跨类型归并。先补齐、合并完整关系，再过滤不足两个成员的孤立项。后台站点字段不占用列表列。
- 集群去重取成员并集；相同、包含、交叉关系不会丢失成员。人工维护和人工暂停优先保留。
- 修复括号备注中的逗号、全半角及原始换行导致的拆名、漏匹配；历史拆分名称依据完整来源名称恢复。编辑框保持每个成员一条逻辑记录。
- 成员核查覆盖设施类型表、设施表、站点表、中继段和集群原表实际设备行。来源中存在但没有中继段的成员仍保留；当前可路由成员不足两个时暂停路由，不虚构资源。
- 新导入、预览、保存、重新打开和在线数据更新均持续使用上述规则。真正的站点冲突、未知成员和人工归属冲突仍保留核对原因。
- 同时附带原始设施站点基线，升级现有数据时自动补齐后台站点证据。已有来源文件优先；不替换数据库，不覆盖人工集群。基线位于资源目录，也能随软件在线更新发布。
- 在线数据更新正确替换旧站点来源，避免设施表更新后保留过期成员；在线发布辅助工具随包提供。

全量核查：历史修复与原表重新导入均得到 321 个集群，完整成员集合一致；原表重新导入后 318 个已确认，3 个需核对。财政局为一个三成员集群，莲下环恢复两个完整名称；宝华苑三个光交全部保留，按同站点证据另补齐一个分纤箱。

## 旧版本升级

下载 FiberRouteR1-R1.4.5-install.zip，完整解压后双击「安装补丁.cmd」，选择原运行目录（里面有「程序」「数据」文件夹）。不要选择刚解压的补丁文件夹，也不要单独解压内部 patch.zip。支持已发布的 R1.3 至 R1.4.4。

关闭主程序、管理方工具及图标工具后安装。安装器先校验补丁和现有版本，备份变更文件，失败自动回退；resources.db、personal.db 和人工记录保留。安装成功后从「光路调度路由查询.exe」启动，标题应为 R1.4.5。

首次启动会整理站点和集群关系，请等待主窗口打开。无需重新导入中继段。以后设施表或集群模板更新，正常导入新表即可自动重算。

## 完整程序包

FiberRouteR1-win-x64-R1.4.5.zip 含 Windows x64 运行环境，完整解压后运行「光路调度路由查询.exe」。业务数据库使用已有数据目录，或由数据导入页导入；完整程序包不含用户个人数据库。已有版本优先使用上面的累计补丁。

## 在线升级

「在线升级辅助」目录含原有 Pages 项目的签名准备、检查和完整下载验证工具。保留原管理工作目录和原签名密钥；使用说明见该目录。交付包完成不代表生产 Pages 已部署，生产站点需上传准备出的文件并验证后再通知客户端检查更新。
