# 光路调度路由查询 R1.4.6

本版累计包含 R1.4.5 及此前修复，并按集群成员类型更正核查和路由状态：

- 集群管理原表明确列出的两个或多个光交箱，直接按成员名单建立关系；不同的所属站点不再使该纯光交箱关系进入「需核对」。其中至少两个成员有中继段端点，才显示「已启用」。
- 一个光交箱与一个或多个分纤箱同属一个站点时，关系确认逻辑保持；只需至少一个成员有中继段端点，即显示「已启用」。
- 混合类型的站点冲突、实际缺失的成员，以及人工关系冲突仍须核对。没有中继段的成员仍保留在名单中，程序不创建虚构的中继段或节点。
- 人工维护集群和人工暂停状态继续优先保留。以后导入新集群表及设施表时自动应用同一规则。

财政局三成员关系在只有光交箱有中继段时已启用；龙星大厦两个光交箱均有中继段，虽站点写法不同仍已确认并启用。莲下环两个光交箱中只有一个有中继段，仍已确认、已暂停。

旧版请用 R1.4.6 累计补丁覆盖安装，保留 resources.db、personal.db 和人工维护记录。首次启动会按新规则重新计算集群状态，不需重新导入原始数据。
