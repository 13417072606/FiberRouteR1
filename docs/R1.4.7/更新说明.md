# 光路调度路由查询 R1.4.7

本版累计包含 R1.4.6 及此前更新。集群确认状态与路由状态分别判断：

- 集群表明确列出的名单成员，即使没有独立设施行或中继段，也只在原因栏提示，不因此将整组标为「需核对」。真正的成员关系冲突、混合类型站点冲突和人工归属重叠仍需核对。
- 纯光交箱集群仍需至少两个成员有中继段端点才参与路由；光交箱与同站点分纤箱组成的集群，或纯分纤箱集群，只需至少一个成员有中继段端点。
- 名单补齐后不足两个成员的孤立关系继续过滤；人工暂停与人工维护关系保持优先。后续导入自动应用相同规则。

历史库直接升级复算：上村宽带环为已确认、已暂停；潮阳综合楼为已确认、已启用；龙潭古寺两个分纤箱为已确认、已启用。原始中继段数据库字节保持不变。
