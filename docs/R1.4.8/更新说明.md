# 光路调度路由查询 R1.4.8

本版累计包含 R1.4.7 及此前更新，保留现有中继段资源库和人工维护记录。

- 集群管理每次导入新表都完整替换旧的表格关系；在线数据更新同样以发布表为完整快照。人工维护和历史确认集群保留。集群成员、确认与路由状态沿用 R1.4.7 的分析规则。
- 机房归属仅从 ODF、光交接箱、光分纤箱、光终端盒、多媒体箱设施表获取明确的机房字段，不再从中继段端点机房生成归属。同一机房的已确认设施可进行内部尾纤逻辑跳通，真实中继段仍按原有芯数和长度校核。
- 设施以原表 ID 识别。跨表同 ID 的认领次序为 `ODF＝光交接箱＞光分纤箱＞光终端盒＞多媒体箱`。同级重复 ID、同名不同 ID 进入需核对，针对当前冲突人工确认前暂停机房内部跳通；新增冲突不能沿用旧确认直接放行。缺少 ID 时仅用完整名称临时匹配；空名称不参与路由。机房名包含“挂墙”的归属过滤。
- 节点类型与机房归属页面的左右默认比例调整为 76:24。首次升级导入本版设施 ID 基线；已由用户导入的设施类别保持优先。

中继段的手动导入和在线更新算法未改动。安装补丁后首次启动需整理机房设施 ID，耗时视电脑性能而定；请勿在整理过程中关闭程序。
