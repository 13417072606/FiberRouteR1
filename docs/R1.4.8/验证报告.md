# R1.4.8 验证

- 核心与 Windows x64 程序编译通过，无编译警告。
- 模拟数据验证：ODF 与光交接箱同级同 ID 进入需核对；新增冲突使旧人工确认重新复核、当前冲突重新确认后可启用；分纤箱同 ID 让位给较高优先级；同一来源更新删除旧归属；手动和在线集群更新完整替换旧表关系；在线数据包同步机房 ID 记录。
- 五类原设施表共 277,160 行，ID 均非空且全局唯一；其中 1 行设施名称为空。实际资源库中有 64,140 个节点匹配机房归属，1 个同名不同 ID 节点进入需核对。首次基线升级与直接导入五类原表的匹配结果一致。
- 中继段现有更新代码保持不变。旧版全面自动测试中的中继段机房归属断言与本版新规则冲突，需更新后再作为完整回归结论；本版未声称 Windows 实机界面验收完成。
- 累计补丁在隔离目录验证了 R1.3 至 R1.4.7 的 13 个已交付版本升级及重复安装；客户数据库字节不变。损坏包、未知来源和写入冲突会拒绝或回退。
- 管理方软件在线更新包已验证版本为 1.4.8，并包含 `资源/机房设施ID基线.db`；尚未发布至用户的更新服务器。
