# R1.4.9 更新说明

本版包含 R1.4.7 及此前版本的累计修改，并替代已撤回、未发布的 R1.4.8 交付包。

- 中继段手动导入和在线完整资源更新都按业务 ID 比对：相同跳过、同 ID 的端点及其他字段变化计为更新、新 ID 新增、新表缺少的旧 ID 删除。新表是完整范围，校验成功后原子替换资源库；空表或重复 ID 拒绝导入，失败时原库保持不变。手动导入显示新增、更新、删除数量。
- 集群表每次手动导入或在线同步均完整替换旧表格关系；本机人工维护与历史人工确认记录保留，冲突时进入核对并暂停对应归并。成员识别、确认及路由启用规则沿用 R1.4.7。
- 机房归属仅使用 ODF、光交接箱、光分纤箱、光终端盒、多媒体箱五类设施表的明确机房字段，不再用中继段端点机房建立归属。按设施类别与 ID 同步：相同跳过、字段变化更新、本次完整类别的新表缺少的旧 ID 删除。手动导入覆盖选定类别；在线完整包覆盖五类。`ODF＝光交接箱＞光分纤箱＞光终端盒＞多媒体箱`；同级 ID 冲突或同名不同 ID 进入需核对。
- 机房字段包含“挂墙”时不建立机房归属。已确认且启用的同机房设施可按尾纤逻辑跳通；真实中继段仍逐段计算芯数与长度。节点类型与机房归属页面默认左 76%、右 24%。

升级保留客户的资源数据库和个人数据库。完整程序包不包含客户数据库；新电脑需复制旧数据目录或导入完整资源表。R1.4.9 的软件包尚未在客户更新服务器发布，在线升级需管理方另行发布本版程序包。
