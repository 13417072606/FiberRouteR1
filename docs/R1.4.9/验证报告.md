# R1.4.9 验证报告

- 核心与 Windows x64 客户端编译通过。20 项契约检查覆盖：手动和在线中继段同 ID 变更及缺失 ID 删除、同内容乱序跳过、重复 ID 拒绝且旧库保留；手动和在线集群全量替换、保留本机人工记录及相同在线包重复更新跳过；机房归属同类别按 ID 更新、缺失删除、空表删除、优先级认领和旧基线不复活已删除记录。
- 五类原设施表共 277,160 行，ID 均非空且全局唯一。机房设施 ID 基线含五类数据。已撤回的 R1.4.8 包不可用于本版校验，也不可安装。
- 累计补丁清单中的 43 个文件已逐项核对 SHA-256；R1.3 至 R1.4.7 共 13 个旧版的客户端与核心程序哈希均在允许升级列表。安装包与完整程序的哈希和 ZIP 完整性、两个安装包分包及六个完整程序分包的合并后哈希均通过核对，补丁不含客户 `resources.db` 与 `personal.db`。
- 旧版全面自动测试中的中继段机房归属断言与现行规则冲突，尚未作为本版完整回归结论；Windows 实机界面验收尚未完成。
- 当前执行环境没有 PowerShell，因此 R1.4.9 安装脚本的 Windows 实际执行尚未完成；发布前仍需在 Windows 上按安装说明跑一次旧版升级和全新安装。
