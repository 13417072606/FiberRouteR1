# R1.4 修改与安装说明

适用于已交付的 R1.3、R1.3.1、R1.3.2、R1.3.3、R1.3.4。关闭主程序后安装，保留原数据库及人工记录，从原快捷方式启动，标题显示R1.4。

1. 节点、集群、机房归属及中继段资源统一青绿色分页；每页可选20/50/100/200条，提供页码与跳页，无原生上下箭头输入框。
2. 节点显示来源表区域；中继段分别显示始端、终端区域。缺失显示“未提供”，明确冲突显示“区域待核对”，不猜写。
3. 长名称按列宽自动换行并计算行高；保存列宽、调整字体、翻页和窗口缩放后重新适配。详情保留完整名称。
4. 表头排序作用于全部筛选结果后再分页；集群及机房增加“需核对”等快捷筛选，显示状态数量、归并状态、完整成员及原因。
5. 机房归属详情增加原表名称、行号、原字段和原值。截图十条记录均来自源表H列“机房名称”，其中光分纤箱6条、光终端盒4条。挂墙/壁挂候选保留原值、标需核对并暂停归并，不凭名称补写真实机房。
6. 设置新增“检测软件更新”“检测数据更新”，独立检测、校验下载、软件升级重启、数据差异预览与应用。保留人工类型、集群、归属和设置；无变化忽略，冲突提示核对。
7. 随包交付管理方发布工具及操作指南。暂无线上地址，默认准确提示“更新服务未配置”；管理方部署国内HTTPS目录并发放公钥配置后启用。

首次启动会导入结构化区域/来源基线，完成后删除安装用基线文件；这不是原始表格，不包含重复的Excel附件。原始表格仍仅在导入时读取。

源表共有154条“挂墙”归属，其中146条设施存在于当前资源库、进入归属列表并暂停归并；8条当前未匹配资源节点，仍保留在复核清单。另111条资源表候选不满足当前归属设施类型条件。候选不等于已经现场判错。

保留既有R1.3.4路由功能和导出结构，包括满足需求筛选、单节点拖动及连线标签跟随、机房折叠、总览跳纤路由、按方案分表、不显示资源追溯和字段说明。

管理方发布工具：在运行目录执行 `.\程序\FiberRoute.Admin.exe` 查看命令。详见“管理方在线更新发布指南.md”。私钥由管理方生成并保管，交付包不含私钥或活动服务器配置。
