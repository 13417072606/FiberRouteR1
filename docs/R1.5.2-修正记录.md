# R1.5.2 优化修正记录

- 启动画面采用方案 C：沿用原有窗口尺寸和配色，使用静态三节点光路线与明确的加载阶段文字，不显示虚构百分比。
- 更新提醒采用方案 A：主窗口右上角“设置”左侧增加“更新”按钮和红点；只有存在待更新软件或数据时显示，完成更新后清除。
- 新安装且没有保存过自定义数据目录时，默认使用安装文件夹内的 `数据` 目录。已有 `data-location.txt` 指向的目录继续有效，避免升级后丢失现有业务数据。
- 应用内资源及在线更新配置继续从安装文件夹内的 `资源` 目录读取；临时下载与升级助手保留在系统临时目录或用户缓存目录，避免占用或锁住正在更新的安装目录。

- 路由查询“最多返回方案”改为“最多候选路由”，取消上下箭头及下拉选择，改为纯数字输入框并校验 1–50，附简短说明；该值只限制最多列出多少条，不决定是否能找到路径，也不改变搜索时间与扩展上限。

- 起终点设施搜索支持空格分隔的多关键词匹配，如 `澄海 看守所`；候选结果须同时包含全部关键词，仍需人工点选具体设施。

此文件记录源码修改；发布 R1.5.2 运行包前仍需完成 Windows 构建和实际启动、更新测试。

## 完整客户端交付修正

原 R1.5.2 `program-source.zip` 仅用于生成在线**软件**更新包，不能作为完整新装包。补发 `full-client.zip`：包含启动器、运行程序、第三方许可、导入模板和空的 `数据` 目录。客户需使用管理方原公开配置生成已配置包，再从现有 Pages 获取最新业务数据。旧版 `服务器部署` 为管理方/IIS 材料，Cloudflare 客户端不需要；旧 `在线升级辅助` 已由程序内升级组件替代；空的报告目录不随包发布。完整包不含管理员私钥、管理工具或陈旧业务数据库。
