# R1.5.5 导入字段映射防错记录

依据 2026-11-03 的 R1.5.4 中继段导入报告：281,465 条读取、272,784 条接入、8,681 条隔离。隔离原因为缺失端点 8,680 条及长度 -1 一条。异常行本身不写入 resources.db。

当前预览代码在表头存在同名字段时精确选中对应字段；上传报告第 261,950 行的原始“长度”为 -1，原始“占用数量”为 0，而程序报“长度非法”，说明该次导入至少“长度”字段实际读取的是原始长度列。截图中下拉框显示“名称/长度→占用数量”的成因尚不能从异常报告确认，不能据此断言 272,784 条已接入数据的字段映射错误。

后续版本应增加以下防错检查：

1. 确认导入前展示最终生效的全部字段映射及前几条对应值；显示的是导入将读取的值，而不只显示控件文字。
2. 表头存在“名称”“长度”等精确同名列时，若用户选择了其他列，应醒目提醒并要求改回或明确确认。
3. 对 ID、两端设施、芯数等必需字段禁止多个目标误选同一源列；可选字段的重复映射给出警告。
4. 导入完成后显示隔离原因分类与条数，并提供逐条清单入口。原始端点缺失仍须由源表修正，不自动从中继段名称猜测设施。

本文件是待实现的版本记录，不代表这些防错检查已经包含在 R1.5.4 中。
