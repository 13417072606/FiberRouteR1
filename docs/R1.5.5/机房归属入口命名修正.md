# R1.5.5 机房归属入口命名修正

确认应用“导入节点类型表”时，程序已对同一批设施表执行 `ApplyRoomFiles`；表格包含设施 ID、设施名称和“所属机房/机房名称”列时，会同步读取归属。若这批表含有效归属字段，无需再从机房归属页面重复导入。

机房归属页两个按钮按用户指定命名为“导入设施清单表”和“导入机房清单表”。前者读取设施名称、ID 与所属机房，仅在需单独更新设施归属时使用；它会按所选设施类别更新归属并移除该类别新表中缺少的旧 ID。后者导入权威“机房名称”名录，按名称核验已录入的设施归属。页面说明同步写明两者关系。

这次只调整入口文案，不改变原有的表格读取、同 ID 优先级、机房名称匹配及未匹配归属暂停归并规则。R1.5.4 已发布包的界面不会自动改变，后续 R1.5.5 构建会带入此修正。
