# 在线发布辅助工具验证

205 项检查通过，包含既有核心检查及以下在线流程回归：

- 从隔离数据库生成标准数据包，复用原签名密钥，资源库及人工库字节保留。
- 同时准备软件和数据渠道；使用真实 `System.Private.CoreLib.dll` 并加入不可压缩数据，产生超过 24 MiB 的软件包，验证自动分片和上传 ZIP 的根目录结构。
- 真正的私钥路径仍拒绝发布；上传包不含管理员私钥、原 personal.db、辅助工具或旧客户端配置备份。
- 软件包包含与当前发布工作目录匹配的公开客户端配置；重复准备数据时保留已发布的软件版本及签名密钥。
- 使用真实客户端的 `Updates.Check` / `Updates.Download`、升级器 `PackageValidator` 和数据包预览逻辑，验证两个渠道完整下载、合并及包内校验。模拟 HTTP 传输用于隔离测试，覆盖缺片、损坏分片、空发布清单，不能用“清单正常”代替实际文件校验。
- PowerShell 脚本通过语法检查；使用隔离的本机进程适配器，完成实际 `Prepare` → 上传 ZIP → 本地公开配置 → `Inspect` 的流程。
