# 2026-10-28 界面变更确认

用户已确认本设计，落实于R1.4.2。效果图为示例方案，不是已安装程序截图；实际运行与检查见../R1.4.2/。此前交付文件保持不变。Cloudflare配置是此前任务，仍未接通，不能在本轮界面修改中声称已上线。

1. 路径示意下方、资源详情上方增加当前方案“跳纤路由”。采用可选择的只读多行文本和“复制路由”按钮；自动换行，不使用省略号替代完整名称。切换方案同步显示；复制内容复用方案导出的跳纤路由格式和实际设备顺序；无跳纤的方案也显示完整起终连接链。保留单节点拖动及连线、距离标签实时跟随。最终文本取自实际路由，不取示例图文字。
2. 中继段资源表格次序为：序号、始端设施、始端区域、始端类型、终端设施、终端区域、终端类型、长度（米）、空闲/总芯、业务状态、操作。筛选次序为：搜索、始端区域、始端类型、终端区域、终端类型、最少空闲芯数、业务状态、重置、导出结果。在基准窗口1380×950下所有筛选及导出同一行，搜索框使用剩余空间；更窄窗口再合理重排，不硬挤压文字。独立的两端筛选和排序功能保留。不能让旧列顺序缓存把新默认顺序覆盖回去。
3. 集群管理增加“成员名单”列，显示实际成员名称，分号分隔并自动换行、测量完整行高。缩小序号、成员数、类型、确认状态、路由状态、操作等短列，给集群名称和成员名单更多空间。删除集群页底部“成员详情与来源”常驻区域；复核操作及需要的来源查看入口保留在复核弹窗。名称完整显示，不能仅依赖悬浮提示。此删除不涉及节点清单右侧详情或机房归属详情。
4. 统一检查文本框及其外框在Windows字体和DPI缩放下的字体高度、内边距、垂直定位和实际客户区，修复底部字符被裁切。覆盖节点搜索、资源搜索、集群搜索、机房搜索、导入路径、下拉输入及数值输入；验证100%、125%、150%缩放。不能靠缩小字体掩盖裁切。
5. 导入路径是ReadOnly TextBox，原生默认背景可产生灰色横条。显式统一为所在白色输入区域底色，保留只读、选择文件、路径查看及复制行为，不移除外框或按钮。

已核对现有源码：ClusterRow尚无成员名单字段；MaintenanceUi.cs挂载了180高度的“成员详情与来源”面板；ResourceWorkspace.cs当前顺序和导出文案需要修改；InputFrame对输入高度和布局变化的处理需加强；importPath为未显式指定背景色的只读TextBox。
