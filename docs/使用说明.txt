纤路 R1 1.0.1 · Windows x64 便携试运行包

一、运行
支持 Windows 10/11 x64。完整解压 ZIP 后，双击“纤路R1.exe”。
必须保留“程序”文件夹；已包含 .NET 和 SQLite 运行组件，无需安装 .NET 或自行编译。
首次启动没有真实资源。此包附有经交接文档提取的 12 条调测数据，非生产数据。
首次使用：数据导入 → 载入调测预览 → 检查预览 → 确认替换并导入。
预期统计：12 段、20 节点、已记录长度 1,659.56 米、逐段空闲累计 40 芯。
界面及 Windows 实机交互尚未在本次 Linux 构建环境验证，请先用调测数据试运行。

二、导入自己的 CSV / XLS / XLSX
选择 CSV、TSV、XLS 或 XLSX。CSV 默认自动识别 UTF-8、GB18030（兼容GBK）、UTF-16 等编码，并识别逗号、分号或制表符；必要时可手动指定编码。
Excel 文件会列出工作表，请选实际数据所在的表。预览成功后检查字段映射及长度单位，再确认导入。
Excel 不需要安装；长编号应在源工作簿中保存为文本。已经由 Excel 数值精度截断的编号无法恢复。文本编号及纯零格式的前导零会保留。
默认单位：米。字段名后 * 为必填。预览仅显示前20条，确认时全量校验。
CSV 可包含带引号的逗号及换行。CSV ID 保存为文本，长数字不会转浮点数。
缺失或零长度仍参与路由；非法芯数、负长度、缺端点等记录隔离，可导出异常。
导入在后台进行，可取消。新库完整性校验并加载连接索引成功后才切换。
失败或取消保留原数据库；数据导入页可回退上一版资源。
不根据业务状态过滤，不拆解中继段名称或关联光缆段，不自动连接同机房的不同设施。

三、路由
顶部导航切换四个页面，统计卡片显示节点、中继段、逐段空闲和数据版本。路由页左侧设置条件，右侧依次显示候选方案、路径图及逐段明细。
在起终点输入关键词，从最多30条匹配结果选择完整名称；可交换起终点。
输入需求芯数、最大跳纤（0–100）、候选数量（1–50，默认8）。
跳纤数 = 中继段数 - 1；0跳只允许直连。中继段暂按双向，路径不重复经过节点。
每段空闲均须满足需求。瓶颈取各段空闲最小值，不能相加。
类型规避仅作用于中间节点，起终点豁免。具体规避与起终点冲突会提示。
多标签用英文分号 ; 分隔，命中任一规避类型即排除。
候选模式按跳纤数排序；其余模式分别按已记录距离、跳纤数或瓶颈空闲计算。
采用按目标指标的优先队列扩展，不是先找任意路径再排序。
默认每次限制10秒、20万次扩展、5万队列状态。触限或停止后结果标明不完整，不能保证最优。
相同指标的方案顺序不保证。长度缺失按已记录部分累计，同时标明未知及零长度段数。
方案导出包含数据版本、筛选条件及逐段详情。
调测例：以 -GF271 结尾设施到 -GF272，需求1、至少1跳，无规避，结果208.21米、1跳、瓶颈1。
路径为连接顺序示意，非地理地图。资源快照不保证实际占用、芯号连续或接续条件。

四、资源与节点类型
资源页支持关键词（含站点、机房）、空闲及端点类型筛选，每页100条；可看完整原始字段并导出。
空闲累计只是各段之和，不代表可用路由数。
节点类型页按关键词和类型检索，最多显示500个匹配；缩小关键词后定位目标。
可单节点修改类型，或导入“节点名称,节点类型”表，支持 CSV / XLS / XLSX、自动识别编码、工作表选择和字段映射。类型导入独立预览位于节点类型页下半区，不混入资源导入预览。
预览显示修改前后类型、未匹配、空类型及同名冲突；确认后仅应用有效行。
可导出预览报告和历史未匹配类型。取消预览不会改库，不因新名称创建连接。
完整名称精确匹配；人工类型按完整名称保留，跨周资源更新仍生效。
若设施改名或消失，会列入历史未匹配报告，需要人工核对；未自动推断改名关系。
资源或经验类型标记“待确认”；同一设施只维护一个类型集合。
修改类型或切换资源后清除旧路由结果。

五、数据位置与备份
个人数据位于：%LOCALAPPDATA%\FiberRouteR1
resources.db 为当前快照，resources.db.bak 为上一版；personal.db 为人工类型、查询及更新设置。
程序升级只替换安装目录中的程序、模板和说明，不覆盖此个人目录或导出结果。
迁移电脑前，请退出程序，备份整个个人目录。敏感资源不会自动上传。
导出默认放在解压目录“导出结果”。CSV用Excel打开时，请将ID列按文本导入，防止Excel自行改写长数字。

六、在线更新
本包默认“未配置更新源”，不会伪报已同步。未联网或未配置时仍可使用本地资源。
管理员需要先落实真实HTTPS发布地址及RSA公钥，在数据导入页保存。
启动自动检查：同源HTTPS清单 → RSA-PSS SHA256签名 → 包大小及SHA256 → 验证导入/替换。
资源包为UTF-8 CSV（米），资源版本与程序版本分开；更新失败保留原版。
程序包校验后等待用户选择重启，由更新助手在主程序退出后替换，并保留程序备份。
程序更新失败会尝试恢复，详情见解压目录“更新失败.txt”。
资源版本、更新时间显示在更新状态栏，资源可用“回退上一版”切换。
发布端协议及签名工具位于项目 docs/更新发布.md、scripts/sign-release.py，仅管理员使用。
真实托管、五台客户端同步、国内访问稳定性及Windows更新助手尚未实测。
不要把长期下载凭据或签名私钥放入公开程序。此版本没有内置服务账户。
