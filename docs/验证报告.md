# 纤路 R1.1 修正版验证报告

日期：2026-10-25。程序版本：1.1.0。基于用户交接包源码，在独立目录实现；未覆盖原main仓库，未发布GitHub分支或Release。

## 本次修复

- CSV由默认UTF-8改为严格自动编码检测：UTF-8含/无BOM、UTF-16大小端及预期无BOM输入、GBK/GB18030。先全文件流式检测，无法可靠识别时提示选择编码，不用替换字符隐藏解码失败。
- 根据文件内容区分文本和Excel，阻止Excel二进制被当作CSV。新增ExcelDataReader 3.7.0（MIT）原生读取XLS及XLSX，工作表选择、预览、字段映射、后台逐行入库；资源和节点类型表均支持。
- Excel文本ID保留长数字与前导零。超过15位数值ID明确中止并说明可能已丢精度，不承诺恢复原始数字。纯零数字格式可保留显示的前导零。
- 四页重新组织：品牌与导航；路由页30/70双栏配置与结果，绘制实际节点及连线，可滚动；资源页统计卡和分页查询；类型页独立维护与匹配预览；导入页设置/映射和校验预览分栏，在线更新配置收入单独对话框。
- 保留原路由硬条件、平行边、缺失/零长度口径、临时SQLite分批事务、校验后切换、失败或取消保留原库、人工设置分库和资源回退机制。未修改Routing.cs算法。

## Windows试用建议

完整解压，双击“纤路R1.exe”。先到数据导入页载入调测数据并确认：12段、20节点、1659.56米、逐段空闲40芯。查询GF271→GF272，需求1芯、最大跳纤至少1、无规避，应有208.21米/1跳/瓶颈1方案；再用自己的CSV或Excel选择工作表、检查中文与ID预览后导入。已有数据先退出旧程序并备份整个 `%LOCALAPPDATA%\FiberRouteR1`，修正版继续使用此个人目录。
