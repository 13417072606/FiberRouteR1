# 光路调度智能分析 R1.4.1 修订包

[下载完整修订安装包](FiberRouteR1-R1.4.1-install.zip?raw=true) · [管理员PowerShell下载脚本](Download-Install-R1.4.1.ps1?raw=true) · [修改清单](../../docs/R1.4.1/R1.4.1修改清单.md) · [实际运行与验证](../../docs/R1.4.1/实际运行/)

适用于已交付R1.3、R1.3.1、R1.3.2、R1.3.3、R1.3.4及R1.4，包含此前修改，无须逐个安装。关闭主程序、管理方工具和品牌工具，使用PowerShell下载脚本，选择原运行目录。保留数据库与人工记录，从原快捷方式启动，标题R1.4.1。内部patch.zip不要再次解压。

安装后原运行目录新增：

- 管理方发布工具.exe：图形向导，按四步生成包、配置服务、签名、发布及验证。
- 更换品牌图标.exe：选择原始PNG，等比生成图标并同步更新启动器、标题栏、任务栏和快捷方式所用资源。原PNG未收到，因此需在本机选择一次；没有把简化绘制版冒充原图。
- 服务器部署：Windows/IIS部署脚本、静态读取配置及说明。已确认单位有Windows服务器，但真实外网网址、站点名与访问方式尚待提供，当前无活动服务器配置。

[管理方EXE使用说明](../../docs/R1.4.1/管理方EXE使用说明.md) · [Windows服务器部署资料ZIP](FiberRouteR1-Windows-Server-Kit-R1.4.1.zip?raw=true)

若管理方电脑已安装本修订包，直接使用原运行目录的管理方EXE即可；单位服务器需要独立工具时，可下载[自包含管理工具包（约68MiB）](FiberRouteR1-Publisher-win-x64-R1.4.1.zip?raw=true)，全部解压后双击EXE，保留“程序”文件夹。另有20,000,000字节分卷及SHA256，见Tools-SHA256.json；分卷须按顺序二进制拼接，不能分别解压。

验证：核心160项；Wine10实际界面100%/150%各73项；全量272,561条中继段与264,608节点及既有208.21米、2044.87米样例；六个旧版升级/重复安装、无效包拒绝、安装故障回退、原生双EXE启动、品牌PNG原字节/比例/透明留边/PE资源更新和软件升级后品牌保留。单位IIS脚本完成语法与XML检查，真实服务器、外网及原生Windows部署仍待网管配合验证。

客户首次使用在线软件更新前应安装R1.4.1修订包，以获得新的升级器。之后管理方发布新版本，客户分别检测软件和数据更新。数据通道兼容R1.4，传输整理后快照，本地按差异应用并忽略无变化、保留人工记录。

各文件大小与SHA256见[安装校验](SHA256.json)及[工具校验](Tools-SHA256.json)。此前正式交付文件不变。
