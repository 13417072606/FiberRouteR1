# R1.4.3 光路调度路由查询

下载完整安装包FiberRouteR1-R1.4.3-install.zip，全部解压后双击“安装补丁.cmd”，选择原运行目录。不要再次解压内部patch.zip。适用于已发布R1.3至R1.4.2，保留数据库及人工记录，继续使用原完整便携运行库，不要求安装.NET。

本目录为公开代码补丁，不含本次提供的原表、专用站点修复数据库或签名私钥。公开补丁用户在升级后依次重新导入两张设施类型表，再导入集群表，即可补齐站点并重新分析现有关系。管理员已收到专用修复包时，用专用包即可自动补入站点与原始集群行。

新增“光路调度路由查询.exe”，旧快捷方式兼容。更新服务继续使用管理方原工作目录和签名私钥；Cloudflare客户HTTPS地址保持https://guangludiaodu.pages.dev/，服务器发布目录留空。新包自动分24MiB片，先在一台R1.4.3客户机验证，再分发客户配置。
