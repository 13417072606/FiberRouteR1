# R1.4.9 交付

已安装 R1.3 至 R1.4.7：下载 `FiberRouteR1-R1.4.9-install.zip`。如单文件下载失败，下载 `.001`、`.002` 两个安装包分包和 `Join-R1.4.9-Install.cmd`、`Join-R1.4.9-Install.ps1`，放在同一文件夹，双击 `.cmd` 校验并合并出安装包。完整解压安装包，退出程序后双击「安装补丁.cmd」，选择原运行目录。

全新安装：下载 `FiberRouteR1-win-x64-R1.4.9.zip`；若单文件下载困难，将 `.001` 至 `.006` 六个完整程序分包与 `Join-R1.4.9-Full.cmd`、`Join-R1.4.9-Full.ps1` 放在同一文件夹，双击 `.cmd` 校验并合并，再解压。完整程序不包含客户数据库，需复制原数据目录或重新导入完整数据。

两个安装包分包均小于 15 MiB，完整程序分包均不超过 15 MiB。文件大小和 SHA-256 见 `SHA256.json`；逻辑与验证见 `docs/R1.4.9/`。软件在线更新需要管理方将本版程序包发布到既有更新服务，本次离线交付不会自动发布。
