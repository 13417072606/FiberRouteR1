R1.4.9 累计补丁

已安装 R1.3 至 R1.4.7：完整解压 FiberRouteR1-R1.4.9-install.zip，退出主程序和管理工具，双击“安装补丁.cmd”，选择原运行目录。补丁保留 personal.db、resources.db 和客户人工维护记录。

全新电脑：下载并合并完整程序分包，解压 FiberRouteR1-win-x64-R1.4.9.zip，按原有方式配置数据目录和更新服务。程序包不含客户资源数据库；请复制原运行目录的“数据”目录，或导入完整中继段及五类设施表。

中继段无论手动或在线更新，均以新完整表覆盖该范围：按 ID 比对，相同跳过、变化更新、旧 ID 缺失则删除。集群表每次完整替换表格关系，保留本机人工维护和历史人工确认。机房归属对本次覆盖的设施类别按 ID 同步，缺失旧 ID 删除；未选择的其他类别不受手动导入影响。

首次启动会整理设施 ID 与机房归属。ODF 和光交接箱同级同 ID 冲突、同名不同 ID 会列为需核对，确认前不参与机房内部跳通。
